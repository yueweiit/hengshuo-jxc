# 部署、业务启用与财务放行清单

本清单用于新的部署环境，不能据此推定任何生产环境已经确认或放行。公开源码绑定见 [发布清单](../../docs/releases/2026-10-20-source-binding.json)；现场执行收据、截图、数据库核对和秘密保存在非公开位置。

## 部署材料

- [ ] 主机／环境责任人确认资源归属、宿主余量、既有站点和端口冲突；只变更本系统准确命名的资源。
- [ ] 业务域名、DNS 管理、证书安装与续期责任确认；`erp.example.com` 等模板值已替换并核验。
- [ ] 应用、网关、PostgreSQL、对象存储镜像来源、安全审核及完整不可变摘要确认；jar／dist 提取字节与已测制品一致。
- [ ] 专属数据库、网络、卷、bucket 和准确目标身份确认；长期容器不发布数据库、API 或对象公网端口。
- [ ] owner／runtime／对象初始化／对象运行身份分离，秘密仓库外托管；应用无 owner 秘密，Flyway 关闭，迁移单独受控执行。
- [ ] 非 root、只读根、最小能力、文件实际所有者／权限、日志轮转和恢复材料检查通过。
- [ ] HTTPS upstream 证书及 Host 校验、外来 forwarded headers 清理、健康和能力 readiness 检查通过。

## 普通业务启用

- [ ] 正式经营主体、门店、仓库名称／编码、本位币、时区和首个业务期间由当地负责人确认。临时名称必须清楚标识待复核。
- [ ] 按原国家／账套服务完成配置与启用，普通交易仅 ACTIVE；停用国家保留原授权下历史只读。使用原期间初始化入口，不制造期初事实。
- [ ] 中国采购来源、供应商来源国及采购币种与经营端归属分别维护；不以 MX 账套限制 CN 供应商或 CNY 采购。
- [ ] 实际业务人员、角色／字段权限、账套／门店／仓库范围和独立审核人确认，组合授权通过原原子入口保存，不绕过权限上界。
- [ ] 所需商品、单位／换算、供应商、客户、价格、授信、上下限和审批规则由业务人员录入真实资料。
- [ ] 采购／销售的新增、保存、编辑、审核及所需收发货、收付款、退货主流程逐项在原页面验收；API 准备、参数拒绝、表单打开和实际业务执行分开记录。
- [ ] 按已批准范围保留财务限制：无记账／冲销／结账／反结账权限，会计 worker 关闭，代理拒绝对应财务与未复核期初／模板工厂入口。

国家／账套启用、开放业务期间及业务管理员登录不表示已确认零期初；缺少某项真实资料只阻断需要该资料的能力。未知价格、成本、汇率和金额保持未知，不静默填零。

## 期初与财务启用

- [ ] 实际启用截止日、主档、库存、AR／预收、AP／预付、GL、未完采购及在途资料有来源和确认人。
- [ ] 原统一导入完成文件 hash、预校验、预览、来源标识、目标映射及原子确认；总账与子账分别录入、独立核对，不相互反推。
- [ ] 账套科目、辅助核算、报表映射、汇率、计价方法、资金账户及银行加密密钥已复核；缺率、缺成本或未知金额不补零。
- [ ] 采购成本继续使用原确认；缺少已确认账单对应时暂停该来源自动记账，显式关联后按冻结本金生成，不重算历史汇率或凑平核对差异。
- [ ] 审核与记账人员分离，当前权限及数据范围再次核验；冲销、结账、反结账和快照原规则已独立验收。
- [ ] 待成本、未解释事件、待审凭证、子账／总账差异及后续期间依赖逐项处理；真实不明差异继续阻断相关财务能力。
- [ ] 财务开放另有明确授权；按既有服务和精确路径调整权限、代理及会计 worker，不因普通业务开放自动扩大授权。

## 恢复、容量与责任

- [ ] 预计总用户／高峰并发、单据行数、附件容量及增长量确认，资源预算与容量告警阈值有依据。
- [ ] 可停写窗口、RPO、RTO、备份／WAL／对象保留天数及容量策略确认。
- [ ] 独立备份位置与独立密钥保管人确认；明确临时本机策略时沿用原 `LOCAL_ONLY_TEMPORARY` 门禁，不承诺整机丢失恢复。
- [ ] 同镜像、同 schema 的加密／解封、准确白名单恢复、全表／序列／附件及非空业务图核对通过；源保留和源丢失演练分别标识。
- [ ] Worker 真实终止与重启唯一效果、撤权拒绝、本人新会话重试、积压／失败告警投递和外部值守完成验收。
- [ ] 在确认规模验证普通请求 p95≤2 秒，另记录结账锁等待、导出积压、备份停写及真实恢复耗时；未测项保持待确认。
- [ ] 运维／告警／证书续期／秘密轮换／恢复责任人，以及各国业务和财务配置负责人确认。

## 记录与未处理事项

每次执行绑定精确源码、jar、dist、镜像摘要和 schema 合同。新增迁移必须同步全表清单、RLS、外键、函数及停写门检查；不能忽略未知对象。旧测试和截图保留原身份，未执行项不标通过。

Vite 大包、旧记录缺少确认人／时间、私有孤儿附件及隔离演练产物按实际影响维护，旧事实不猜补、对象不擅自删除。Mock 保留独立演示和原回归，只有真实调用及演示用途全部退出后才删除。完整历史交易迁移、外部付款执行、税务和外部平台接口不在本次部署模板范围；外部 AI 未配置时明确不可用。
