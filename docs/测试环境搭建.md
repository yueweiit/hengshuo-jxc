# 测试环境搭建

本文定义恒烁进销存的开发、自动化测试、手工页面测试、Docker 验收和生产边界。自动化测试使用临时 PostgreSQL 和 MinIO；手工页面测试一轮使用同一套持久化数据，两者不能混用。第 7 节是本机第四至第六阶段的连续操作说明。

## 1. 环境边界

| 环境 | 启动方式 | 数据和存储 | 是否保留 | 用途 |
| --- | --- | --- | --- | --- |
| 源码联调 | Java + Vite 直接启动 | `jxc-server/.env`、`jxc-web/.env.local`；当前通常连接 `127.0.0.1:55438` 和本机 MinIO | 保留 | 开发调试，不作为自动化测试目标 |
| 自动化测试 | `jxc-server/scripts/test-env.ps1` | Testcontainers 临时 PostgreSQL 16 和 MinIO；随机凭据、动态端口、独立数据库 | 每轮结束销毁 | 后端真实数据库测试、附件测试、前端回归和构建 |
| 手工隔离基础设施 | `jxc-server/compose.test.yml` | 固定端口 `55438`、`59000/59001`；仅启动 PostgreSQL 和 MinIO | 当前没有显式命名卷，不能默认承诺容器重建后保留 | 调试基础设施，不是自动化测试快速入口 |
| Docker 验收 | `runtime/docker/compose.yml` | 应用和网关容器复用现有 PostgreSQL `jxc_m01_isolated` 与本机 MinIO | 保留 | 本机 Docker 入口；不能当作每轮独立测试环境 |
| 生产 | `deploy/production/compose.yml` | 专用数据库、专用对象存储、独立网络和 secrets | 按生产策略保留 | 正式运行；不能从开发或测试脚本启动 |

自动化测试的 PostgreSQL 由 `PgDatabase` 启动，MinIO 由 `MinioTestStorage` 启动。每次 Maven 测试进程使用一组新容器；同一轮中的测试类共享容器，但每个测试方法会重置业务 fixture。Testcontainers 的清理失败时，必须记录残留容器并手工确认，不得把下一轮测试接到残留容器上。

## 2. 快速运行测试环境

在仓库根目录执行：

```powershell
.\jxc-server\scripts\test-env.ps1 -Action All
```

只运行后端真实 PostgreSQL/MinIO 测试：

```powershell
.\jxc-server\scripts\test-env.ps1 -Action Backend
```

只运行前端隔离回归和真实 API 构建：

```powershell
.\jxc-server\scripts\test-env.ps1 -Action Frontend
```

脚本先执行 `rtk docker info`。Docker 不可用、Testcontainers 无法拉起容器或任一测试命令失败时，脚本返回失败，不把空结果或跳过测试当成通过。脚本不会读取 `jxc-server/.env`，也不会启动 `runtime/docker/compose.yml`。

后端测试实际执行：

```powershell
Push-Location jxc-server
.\mvnw.cmd -Ppg-it -Dspring-boot.repackage.skip=true verify
Pop-Location
```

其中 `pg-it` 使用真实 PostgreSQL；附件场景同时使用真实 MinIO。Docker 不可用时测试必须失败，不能改用 H2、Mock 数据库或开发库代替。

注意：跳过 Spring Boot repackage 并不能阻止 Maven 的 package 阶段覆盖 `target/jxc-app-0.1.0-SNAPSHOT.jar`。此前自动化构建已经把该文件覆盖成薄 JAR，不能再直接用它启动应用。运行中的应用应使用独立、已核验的完整构建产物；下文使用原本已登记 SHA256 的 `runtime/docker/release-artifacts/app.jar`，不再次构建或覆盖开发产物。

Windows 上优先使用仓库内的 `mvnw.cmd`。如果主机只有 PowerShell Core（`pwsh.exe`）而没有 Windows PowerShell（`powershell.exe`），快速入口会校验并回退到已安装的 Apache Maven 3.9.16；版本不符时直接失败，不会静默使用其他 Maven 版本。

## 3. 源码联调与测试切换

此前源码联调记录为前端 `5173`、后端 `8080`、PostgreSQL `55438`。本次确认的新方案统一使用前端 `60`、后端 `90`，开发和测试轮流运行，通过指定不同 `.env` 选择数据环境，操作见第 7 节。修改配置本身不会启动应用或自动完成切换。

自动化测试不需要切换开发 `.env`。运行 `test-env.ps1` 时，Spring 测试通过 `@DynamicPropertySource` 接收 Testcontainers 的 JDBC 地址、用户名、密码和 MinIO endpoint；因此不会因为 `.env` 未加载而落到 `application.yml` 的默认数据库 `jxc`。

Testcontainers 的随机后端端口由集成测试控制，不是本次手工页面测试入口。页面验收使用第 7 节的固定端口和持久化测试数据，并记录数据库名、构建版本、操作者和页面证据。自动化测试结果只能填写“自动化验证”，不能填写“页面验收”。

## 4. 数据和凭据规则

- Testcontainers 使用随机数据库密码和 MinIO 密钥；测试代码中的 bucket 只用于测试，不得作为生产凭据。
- 自动化测试不创建或读取开发账号、生产账号、真实业务数据或生产对象。
- `compose.test.yml` 的密码变量必须显式设置；不允许把密码写入命令参数、提交到仓库或复用生产密钥。
- 测试失败后先查看 Testcontainers/Ryuk 的容器状态，再开始下一轮；不得把残留容器当成下一轮环境。
- `runtime/docker` 的 `application.env`、本机 `.env` 和生产 secrets 不得互相复制。
- 生产 Compose 必须继续提供明确的 `JXC_DB_URL`、`JXC_EXPECT_DATABASE`、对象存储 endpoint 和 secrets；测试脚本不读取这些配置。

## 5. 环境误连检查

自动化测试通过动态 JDBC 配置连接 `jxc_m01_test`，不接受外部 `JXC_DB_URL` 覆盖。页面验收或手工 Compose 启动前，必须记录并核对：

1. `current_database()` 的结果和登记的测试数据库名；
2. PostgreSQL 主机、端口和 Compose 项目名；
3. MinIO endpoint、bucket 和凭据来源；
4. 应用镜像或源码 Git SHA；
5. 当前环境是否允许写入。

任一项无法确认时停止测试，不把连接失败、权限失败或空列表解释为业务无数据。

## 6. 已知边界

- 当前 `compose.test.yml` 没有显式命名数据卷，不能用它承诺跨容器重建的数据保留。
- 当前 Docker 验收入口复用本机 PostgreSQL 和 MinIO，不是生产同构环境，也不是每轮独立环境。
- Testcontainers 只覆盖自动化测试；真实页面、登录、页面交互和页面可用性仍需单独验收。

## 7. 第四至第六阶段：由操作者连续执行

本节提供需要操作者创建的文件内容和执行命令，不代表这些文件已经创建或应用已经启动。本文内代码只在完成文末验证后，才能分别登记相应验证结果。不要把代码示例或接口检查登记成页面验收。

已确认的方案：前端 `60`、后端 `90`，开发和测试轮流运行；测试第一轮沿用 `jxc-test-01` 的数据库、MinIO 和命名数据卷。实际配置目录是 `C:\project\jxc\runtime\jxc-env`，测试 MinIO 实际端口是 `49010/49011`，以现场配置为准，不再使用此前示例的 `59010/59011`。

前次检查记录：两个 `.env` 的原有必要字段非空，测试库 `jxc_test_01` 尚无业务表和 `jxc_app/jxc_owner` 角色。第 7.2 节的新字段仍需操作者补充；字段非空不能证明密码正确。2026-10-21 复查确认初始化镜像内的 JAR 与本机完整 JAR 的登记 SHA256 一致。

### 7.1 文件职责与复用

所有本机工具先放在 Git 已忽略的 `runtime/jxc-env`，不修改公共 Vite 配置，不提交本机密钥。正式将工具纳入源码管理时，应在特性分支开发及提交。

### 7.3 创建共用配置工具

用文本编辑器在 `runtime/jxc-env` 新建 `local-env.mjs`，内容如下。要求 Node.js 24 和 Java 21 以上；本机已检查 Node.js 24 的内置 `.env` 解析器可用。密码只在子进程环境或标准输入中传递，不放入命令参数。

```javascript
import { parseEnv } from 'node:util';
import { readFileSync, existsSync, mkdirSync, writeFileSync } from 'node:fs';
import { resolve, dirname, join } from 'node:path';
import { fileURLToPath } from 'node:url';
import { createHash } from 'node:crypto';
import { spawnSync } from 'node:child_process';

export const localDirectory = () => dirname(fileURLToPath(import.meta.url));
export const projectRoot = () => resolve(localDirectory(), '../..');
const required = ['JXC_ENV', 'JXC_WEB_PORT', 'JXC_PORT', 'JXC_BIND_ADDRESS',
  'JXC_DB_URL', 'JXC_DB_USER', 'JXC_DB_PASSWORD', 'JXC_EXPECT_DATABASE',
  'JXC_STORAGE_ENDPOINT', 'JXC_STORAGE_ACCESS_KEY', 'JXC_STORAGE_SECRET_KEY',
  'JXC_STORAGE_BUCKET', 'JXC_BANK_ENCRYPTION_KEY', 'JXC_APP_JAR',
  'JXC_APP_SHA256', 'JXC_DB_CONTAINER', 'JXC_ENV_ID', 'VITE_API_TARGET', 'VITE_USE_MOCK'];

export function validate(c) {
  for (const key of required) if (!c[key]?.trim()) throw Error(`缺少配置：${key}`);
  if (!['development', 'test'].includes(c.JXC_ENV)) throw Error('此工具只接受开发或测试配置');
  if (!/^[a-z][a-z0-9-]+$/.test(c.JXC_ENV_ID)) throw Error('环境标识不合法');
  const testId = /^jxc-test-[a-z0-9]+(?:-[a-z0-9]+)*$/.test(c.JXC_ENV_ID);
  if ((c.JXC_ENV === 'test') !== testId) throw Error('环境类型与项目标识不匹配');
  if (c.JXC_ENV === 'test') {
    for (const name of ['JXC_MINIO_CONTAINER', 'JXC_DATA_NETWORK'])
      if (!c[name]?.trim()) throw Error(`缺少配置：${name}`);
    if (c.JXC_EXPECT_DATABASE !== c.JXC_ENV_ID.replaceAll('-', '_') ||
        c.JXC_STORAGE_BUCKET !== `${c.JXC_ENV_ID}-evidence`)
      throw Error('测试数据库或附件桶不属于本轮环境');
  }
  for (const key of ['JXC_PORT', 'JXC_WEB_PORT']) {
    if (!/^\d+$/.test(c[key]) || Number(c[key]) < 1 || Number(c[key]) > 65535)
      throw Error(`端口不合法：${key}`);
  }
  if (Number(c.JXC_PORT) === Number(c.JXC_WEB_PORT)) throw Error('前后端不能使用同一端口');
  if (c.JXC_BIND_ADDRESS !== '127.0.0.1') throw Error('本机工具只绑定 127.0.0.1');
  if (!c.JXC_DB_URL.startsWith('jdbc:postgresql://')) throw Error('数据库地址格式不正确');
  const database = new URL(c.JXC_DB_URL.slice(5));
  if (!['127.0.0.1', 'localhost'].includes(database.hostname) || database.username ||
      database.password || database.search || database.hash ||
      decodeURIComponent(database.pathname.slice(1)) !== c.JXC_EXPECT_DATABASE)
    throw Error('数据库目标与声明不匹配，或连接串包含不允许的参数');
  const storage = new URL(c.JXC_STORAGE_ENDPOINT);
  if (!['127.0.0.1', 'localhost'].includes(storage.hostname) ||
      storage.protocol !== 'http:' || storage.username || storage.password ||
      storage.search || storage.hash || storage.pathname !== '/')
    throw Error('本机 MinIO 地址不合法');
  const api = new URL(c.VITE_API_TARGET);
  if (!['127.0.0.1', 'localhost'].includes(api.hostname) || api.protocol !== 'http:' ||
      (api.port || '80') !== c.JXC_PORT || api.pathname !== '/' ||
      api.search || api.hash || api.username || api.password || c.VITE_USE_MOCK !== 'false')
    throw Error('前端 API 目标与后端不一致，或启用了 Mock');
  if (!/^[a-z_][a-z0-9_]{0,62}$/.test(c.JXC_DB_USER) || c.JXC_DB_USER === 'postgres')
    throw Error('应用数据库账号不合法');
  const key = Buffer.from(c.JXC_BANK_ENCRYPTION_KEY, 'base64');
  if (key.length !== 32 || key.toString('base64') !== c.JXC_BANK_ENCRYPTION_KEY)
    throw Error('银行信息加密密钥必须是 32 字节的标准 Base64');
  if (!/^[a-f0-9]{64}$/i.test(c.JXC_APP_SHA256)) throw Error('JAR 校验值格式不正确');
  for (const [name, value] of Object.entries(c))
    if (/PASSWORD|SECRET/.test(name) && /[\r\n]/.test(value))
      throw Error(`密码不能包含换行：${name}`);
  return c;
}

export function config(file) {
  if (!file) throw Error('必须明确指定 .env 文件路径');
  return { ...validate(parseEnv(readFileSync(resolve(file), 'utf8'))), file: resolve(file) };
}

export function baseEnvironment() {
  const result = {};
  for (const key of ['PATH', 'SystemRoot', 'WINDIR', 'TEMP', 'TMP', 'USERPROFILE',
    'APPDATA', 'LOCALAPPDATA', 'JAVA_HOME', 'COMSPEC', 'PATHEXT', 'USERNAME'])
    if (process.env[key] !== undefined) result[key] = process.env[key];
  return result;
}

export function applicationEnvironment(c) {
  const result = baseEnvironment();
  for (const key of ['JXC_BIND_ADDRESS', 'JXC_PORT', 'JXC_DB_URL', 'JXC_DB_USER',
    'JXC_DB_PASSWORD', 'JXC_EXPECT_DATABASE', 'JXC_STORAGE_ENDPOINT',
    'JXC_STORAGE_ACCESS_KEY', 'JXC_STORAGE_SECRET_KEY', 'JXC_STORAGE_BUCKET',
    'JXC_BANK_ENCRYPTION_KEY']) result[key] = c[key];
  result.SPRING_FLYWAY_ENABLED = 'false';
  return result;
}

export function redact(text, c) {
  let result = String(text);
  for (const [key, value] of Object.entries(c)) if (/PASSWORD|SECRET|ENCRYPTION_KEY/.test(key) && value)
    for (const form of [value, encodeURIComponent(value)]) result = result.replaceAll(form, '[REDACTED]');
  return result;
}

export function run(c, label, program, args, options = {}) {
  const result = spawnSync(program, args, { cwd: projectRoot(), encoding: 'utf8',
    maxBuffer: 16 * 1024 * 1024, env: baseEnvironment(), ...options });
  if (result.error || result.status !== 0)
    throw Error(`${label}失败：${redact(result.error?.message || result.stderr || result.stdout || `exit=${result.status}`, c)}`);
  return result.stdout.trim();
}
export const docker = (c, args, options = {}) => run(c, 'Docker 操作', 'rtk', ['proxy', 'docker', ...args], options);

export function libraries(c) {
  const digest = createHash('sha256').update(readFileSync(c.JXC_APP_JAR)).digest('hex');
  if (digest !== c.JXC_APP_SHA256.toLowerCase()) throw Error('完整 JAR 与登记的 SHA256 不一致');
  const cache = join(localDirectory(), '.cache', digest);
  if (!existsSync(join(cache, 'ready'))) {
    mkdirSync(cache, { recursive: true });
    run(c, '提取已核验依赖', 'jar', ['xf', resolve(c.JXC_APP_JAR), 'BOOT-INF/lib'], { cwd: cache });
    writeFileSync(join(cache, 'ready'), digest, 'utf8');
  }
  return join(cache, 'BOOT-INF/lib/*');
}

export function checkContainer(c) {
  const targets = [[c.JXC_DB_CONTAINER, '5432/tcp',
    new URL(c.JXC_DB_URL.slice(5)).port || '5432', 'pgdata', '/var/lib/postgresql/data']];
  if (c.JXC_ENV === 'test') targets.push([c.JXC_MINIO_CONTAINER, '9000/tcp',
    new URL(c.JXC_STORAGE_ENDPOINT).port || '80', 'miniodata', '/data']);
  for (const [container, exposed, port, volume, destination] of targets) {
    const project = docker(c, ['inspect', '--format', '{{index .Config.Labels "com.docker.compose.project"}}', container]);
    if (project !== c.JXC_ENV_ID) throw Error('容器项目与所选环境不匹配');
    const mappings = JSON.parse(docker(c, ['inspect', '--format', '{{json .NetworkSettings.Ports}}', container]));
    if (!(mappings[exposed] || []).some(p => p.HostPort === port &&
        ['127.0.0.1', '0.0.0.0'].includes(p.HostIp)))
      throw Error('声明的容器与连接端口不匹配');
    if (c.JXC_ENV === 'test') {
      const networks = JSON.parse(docker(c, ['inspect', '--format', '{{json .NetworkSettings.Networks}}', container]));
      const mounts = JSON.parse(docker(c, ['inspect', '--format', '{{json .Mounts}}', container]));
      if (!Object.hasOwn(networks, c.JXC_DATA_NETWORK) ||
          !mounts.some(m => m.Type === 'volume' && m.Name === `${c.JXC_ENV_ID}_${volume}` &&
            m.Destination === destination && m.RW))
        throw Error('测试容器未使用本轮网络及持久化数据卷');
    }
  }
}

export function probe(c, mode = 'check') {
  return JSON.parse(run(c, '数据库和附件检查', 'java', ['-Dfile.encoding=UTF-8',
    '-cp', libraries(c), join(localDirectory(), 'LocalEnvironmentCheck.java'), mode],
  { env: applicationEnvironment(c) }));
}
```

### 7.4 创建只读连接检查器

同目录新建 `LocalEnvironmentCheck.java`。此文件通过现有 SDK 检查真实数据库身份和真实 MinIO 访问权限，避免只检查 `.env` 中的字符串。

```java
import java.sql.DriverManager;
import java.util.*;
import com.hs.jxc.common.api.JsonCodec;
import com.hs.jxc.sys.service.PermissionCatalog;
import io.minio.*;

class LocalEnvironmentCheck {
    static String env(String key) {
        String value = System.getenv(key);
        if (value == null || value.isBlank()) throw new IllegalArgumentException(key);
        return value;
    }
    public static void main(String[] args) {
        String phase = "permissions";
        try {
            if (args.length == 1 && args[0].equals("permissions")) {
                var permissions = new ArrayList<String>();
                for (var group : PermissionCatalog.tree())
                    for (Object raw : (List<?>) group.get("children"))
                        permissions.add(String.valueOf(((Map<?, ?>) raw).get("code")));
                var fields = new LinkedHashMap<String, String>();
                for (var group : PermissionCatalog.fieldGroups()) fields.put(group.get("code"), "WRITE");
                System.out.println(new JsonCodec().write(Map.of("permissions", permissions, "fieldPolicies", fields)));
                return;
            }
            phase = "database";
            var properties = new Properties();
            properties.setProperty("user", env("JXC_DB_USER"));
            properties.setProperty("password", env("JXC_DB_PASSWORD"));
            properties.setProperty("connectTimeout", "5");
            properties.setProperty("socketTimeout", "5");
            try (var connection = DriverManager.getConnection(env("JXC_DB_URL"), properties);
                 var statement = connection.createStatement();

                    row.getBoolean(4) || row.getBoolean(5) || row.getBoolean(6))
                    throw new IllegalStateException("DATABASE_IDENTITY_OR_PRIVILEGE_MISMATCH");

                "user", env("JXC_DB_USER"), "storage", env("JXC_STORAGE_ENDPOINT"), "bucket", env("JXC_STORAGE_BUCKET"))));
        } catch (Exception error) {
            System.err.println("ENV_CHECK_FAILED: " + phase + " (" + error.getClass().getSimpleName() + ")");

        }
    }
}
```

### 7.5 创建通用启动器

同目录新建 `start.mjs`。不写死开发或测试的连接；前端通过现有 Vite 的命令参数固定端口，进程级 `VITE_API_TARGET` 优先于旧的 `.env.local`。前端子进程不接收数据库或 MinIO 密码。

当前启动器运行已核验的完整 JAR 和 Vite，不会自动编译 Java 源码。Java 代码变更后，需另行生成独立完整产物，再更新路径及校验值；不要使用已被自动化构建覆盖的开发 `target` 薄 JAR。

```javascript
import { spawn, spawnSync } from 'node:child_process';
import { existsSync } from 'node:fs';
import { join } from 'node:path';
import { createServer } from 'node:net';
import { setTimeout as delay } from 'node:timers/promises';
import { config, checkContainer, probe, applicationEnvironment, baseEnvironment,
  projectRoot, redact } from './local-env.mjs';

const children = [];
let stopping = false;
function stop() {
  if (stopping) return;
  stopping = true;
  for (const item of children) {
    const child = item.process;
    if (!child.pid || item.outcome || child.exitCode !== null || child.signalCode !== null) continue;
    if (process.platform === 'win32') {
      const result = spawnSync('taskkill.exe', ['/PID', String(child.pid), '/T', '/F'],
        { env: baseEnvironment(), encoding: 'utf8', windowsHide: true });
      if (result.error || result.status !== 0) {
        console.error(`停止本启动器的进程 ${child.pid} 失败，请核对该进程；未清理数据容器。`);
        process.exitCode = 1;
      }
    } else child.kill('SIGTERM');
  }
}
function available(port) {
  return new Promise((resolve, reject) => {
    const server = createServer();
    server.once('error', () => reject(Error(`端口 ${port} 已被占用或禁止绑定，请先停止原应用`)));
    server.listen(Number(port), '127.0.0.1', () => server.close(resolve));
  });
}
function child(program, args, options) {
  const result = spawn(program, args, { stdio: 'inherit', ...options });
  const item = { process: result, outcome: null };
  item.done = new Promise(resolve => {
    const finish = outcome => { item.outcome = outcome; resolve(outcome); };
    result.once('error', error => finish({ error: error.message }));
    result.once('exit', (code, signal) => finish({ code, signal }));
  });
  children.push(item);
  return item;
}
let c;
try {
  c = config(process.argv[2]);
  if (process.argv.length > 4 || process.argv.slice(3).some(arg => arg !== '--check'))
    throw Error('不支持的参数');
  checkContainer(c);
  console.log(JSON.stringify({ environment: c.JXC_ENV, ...probe(c) }, null, 2));
  if (!process.argv.includes('--check')) {
    const vite = join(projectRoot(), 'jxc-web/node_modules/vite/bin/vite.js');
    if (!existsSync(vite)) throw Error('缺少已有前端依赖，请先在 jxc-web 安装锁文件对应的依赖');
    await available(c.JXC_PORT);
    await available(c.JXC_WEB_PORT);
    process.once('SIGINT', stop);
    process.once('SIGTERM', stop);
    process.once('exit', stop);
    const backend = child('java', ['-Dfile.encoding=UTF-8', '-jar', c.JXC_APP_JAR],
      { cwd: projectRoot(), env: applicationEnvironment(c) });
    let ready = false;
    let reason = '后端没有返回 UP';
    for (let attempt = 0; attempt < 120 && !stopping; attempt++) {
      if (backend.outcome) throw Error(`后端提前退出：${JSON.stringify(backend.outcome)}`);
      try {
        const response = await fetch(`http://127.0.0.1:${c.JXC_PORT}/actuator/health`, { signal: AbortSignal.timeout(1000) });
        ready = response.ok && (await response.json()).status === 'UP';
        if (ready) break;
      } catch (error) { reason = error.message; }
      await delay(500);
    }
    if (!ready && !stopping) throw Error(`后端启动超时：${reason}`);
    if (!stopping) {
      child(process.execPath, [vite,
        '--host', '127.0.0.1', '--port', c.JXC_WEB_PORT, '--strictPort'],
      { cwd: join(projectRoot(), 'jxc-web'), env: { ...baseEnvironment(),
        VITE_API_TARGET: c.VITE_API_TARGET, VITE_USE_MOCK: 'false' } });
      console.log(`环境 ${c.JXC_ENV}：前端 ${c.JXC_WEB_PORT}，后端 ${c.JXC_PORT}；按 Ctrl+C 停止应用，保留数据容器。`);
      const outcome = await Promise.race(children.map(item => item.done));
      if (!stopping) throw Error(`应用进程退出：${JSON.stringify(outcome)}`);
    }
    stop();
  }
} catch (error) {
  console.error(c ? redact(error.message, c) : error.message);
  stop();
  process.exitCode = 1;
} finally {
  stop();
  await Promise.all(children.map(item => item.done));
}
```
