## 已实现的主流程

- 采购物流：原采购订单、国内实收与出口节点；装运、暂缓、换柜、派送、墨西哥实收及签收；费用暂估/实际关联、原币及确认汇率来源。来源累计使用锁定余额，重复来源行拒绝；有应付历史的采购行不能删除重建，有有效应付占用的实收不能作废，作废账单后才释放额度。
- 库存：唯一 InventoryApi 处理入库、预留、冻结、出库、调拨在途与收货、盘点差异。盘点锁与库存写入互斥；库存汇总、批次、预留和流水在同事务内守恒。调拨部分实收保留在途，差异经原审批后按追回或报损处理，不再次扣减已经调出的实物。
- 销售与应收：沿用价格优先级、原单位换算、手工改价权限、分仓履约、现款证据、授信预占转应收、签收差异；收款确认、分配、核销、反向核销、客户余额及对账。客户/币种闸门跨账套共享，不能把相同额度在两个账套重复使用；修改客户后不能沿用原客户预收款。
- 应付：从真实采购/实收/物流费用生成应付，规范化来源占用、分次开票和额度释放；付款/预付确认、同币与跨币核销、原汇率快照、尾差吸收和撤销。账户必须属于同一来源账套，金额按币种分别展示，历史对账快照按当前字段授权重新裁剪。
- 退货退款：销售原单退货额度预占、分次实收、验货、原价结算、先冲原单未核销应收再形成可退款贷项；退供、AP 贷项和退款审批/证据/支付事实。无原单退货只接受明确且授权的成本来源并强制审批；退款额度与核销争用同一客户余额锁。历史结算保留逐行金额事实，冲销追加反向关联。
- 成本来源：实收冻结 PO 原单位、换算、原币金额、当日确认汇率与本位币金额；出库保存实际消耗批次、计价池组成、方法版本和 COGS；调拨携带原冻结成本，销售退货继承原出库成本。FIFO 与移动平均共用持久计价池，分次出入库/退货累计分摊吸收最后尾差。缺汇率或来源保留 PENDING/null，不能以 0 冒充完整成本。

## 复用与数据库边界

新业务共用原授权闸门、BookGate、PeriodApi、IdempotencyExecutor、附件 PreparedEvidence、审批规则/关键字段快照、审计及 outbox；没有新建支付、权限、审批或事件总线。审批业务回调与任务决定同事务，回调异常会一起回滚。附件内部证据校验不向没有字段权限的操作者暴露对象内容。

Maven 按原模块所有权增加 md、pur、lgs、inv、sal、ar、ap、rtn、cst 及所需 API 构件，拆 API 以消除依赖环；核心操作经同步 API 参与调用方事务，不跨模块调用 Mapper、不通过异步任务补主流程余额。

新增 V003.1、V003.2、V003.3、V004、V004.1：国家/账套/父子复合 FK、来源唯一、非负与累计余额约束、延迟合计检查、期间守卫及事实不可变权限。SchemaIT 动态检查全部实际国家业务表 FORCE RLS 和运行角色非 owner，避免只核对 M1 的固定表数。

保留 `/api/v1`、原权限码、camelCase、分页和 envelope。普通编辑保留 version CAS，动作使用服务端锁定的状态和审批快照；前端新增调用复用 CommandIntent 和 postIdem/putIdem，同意图失败保留 key，成功或修改意图后换 key。适配了现有付款凭据、分次退货数量和计价方法配置入口。Mock 仍供独立演示/回归，未切换生产构建。
