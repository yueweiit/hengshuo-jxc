# ADR 0004：敏感附件按当前来源授权代理下载

日期：2026-10-15。状态：接受用于 M1。

保留 `/api/v1/sys/attachments`、`/{id}/url`、`/{id}/unlink` 及既有 envelope。元数据包括国家、来源类型/ID、状态、对象键、hash 和上传人；对象键不是可分享下载凭证。

敏感业务附件通过应用授权代理读取私有 MinIO 对象。`/{id}/url` 返回应用内下载入口，每次下载（包括新 Range 请求）重新校验当前会话、国家、来源功能权限、来源数据范围、附件有效性及必要字段权限；列表、上传、取 URL、读取、解除关联沿用同一来源链判定。下载入口不能只凭猜到的 ID、旧 URL、旧缓存 JSON 或 bucket 对象键授权。

撤权在下一次 HTTP 请求重新生效。已经传给客户端的字节不能收回，已开始流式响应的中途撤权不宣称即时截断。来源不可见时保持既有 404 隐藏语义，功能权限不足时按原 403 规则。代理对敏感响应避免公共缓存，文件名和类型经安全响应头处理，日志不泄露会话、内部对象键或真实下载签名。

不把长期或短期对象签名 URL 当作即时撤权能力。如以后确需临时公开访问，必须另行说明有效期内的撤权延迟、适用附件范围及审计要求；不能悄悄替换本决策。上传完成与业务绑定校验分开，未知来源/越权来源不可绑定；实际文件存储、大小/hash 校验失败不能留下 ACTIVE 的空壳附件。

M1 验收：未登录、跨国、越权来源、已 unlink、撤销功能/数据/字段授权、旧代理 URL 与新 Range 请求；有权限下载得到真实文件内容及正确 hash。M2 来源尚未实现时默认拒绝，不能因暂时查不到来源表就允许上传下载。
