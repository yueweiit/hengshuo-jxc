# ADR 0003：零会计影响事件在 M3 显式复核

日期：2026-10-15。状态：接受，财务分类实施属于 M3。

业务事件有效，不代表一定产生会计分录。纯数量动作、正确分类为零会计影响的事件和缺成本/汇率/映射的失败事件必须区分。

M1 只保存真实事务 outbox、消费及诊断边界，不自动给事件判定“无影响”。M3 为确实没有会计影响的事件提供显式复核结果，记录事件/来源版本、分类规则或映射版本、复核人、理由与时间。可使用明确 `NO_ACCOUNTING_IMPACT` 分类，但它必须有已复核依据；最终状态字段在 M3 的契约修订中固定。

不为让事件队列清空而生成全零凭证，不把缺金额、缺成本、缺汇率、未复核映射、未确认分摊当成零影响。未完成复核的事件继续待处理并阻断需要完整会计解释的结账检查；明确复核结果作为结账解释的一部分保留。有效负数必须按其调整/冲销语义生成事实，不能因 `amount <= 0` 就静默跳过。

重放、分类修订、跨期更正仍保留原事件与审计，消费者按事件和消费者唯一键实现幂等效果。不能宣称消息只投递一次，不能在 GET 中补生成业务事件或重算事实。

验收留给 M3：正/负/真实零影响/缺数据四类分别覆盖；待处理项不能被零分录清除；复核与规则版本改变可追溯；结账读取同一事实解释。
