# ADR 0002：账套由可信归属唯一解析

日期：2026-10-15。状态：接受用于 M1 及后续业务阶段。

现有 Mock 的 `services/period.ts:activeBook` 取本国第一本 ACTIVE 账套；`assertPeriodOpen` 在没有账套时直接返回。真实服务不能沿用这两个演示便利条件。

服务端从已授权主体、仓店或资金账户的归属解析账套。客户端传入 bookId 只能进一步选择已授权且归属一致的账套，不能覆盖来源。账套、主体、国家、来源引用必须一致，复合 FK 和 RLS 兜底服务层漏过滤。多个候选时返回缺少明确归属的受控错误；没有候选、未启用或未配置期间时阻断，不能跳过期间闸门。

同一个国家可以有多本账套，不能取集合第一本、最新一本或随便一条 ACTIVE。仅在可信筛选后恰好一个合法候选时才允许省略 bookId。读接口也不得通过默认选第一本扩大可见范围。业务日期映射使用该账套期间，后续跨账套调拨须先有已复核会计政策，缺配置先阻断。

M1 的基础档案编辑尚未成为库存、成本或会计事实；M2/M3 命令复用同一 Book/Period API 与数据库守卫。关闭期间测试必须证明写事务取得正确账套共享闸门及数据库拒绝，不能只验证某个 Java if 分支。

验收：两本同国 ACTIVE 账套未选定时失败；显式且授权的合法归属成功；另一国家/主体/未授权账套被拒绝；无账套及关闭期间均无任何事实副作用。
